# Аналитическая платформа биржевых событий

## О проекте

Предполагаются два взаимодополняющих направления:

- **Анализ и прогнозирование динамики котировок** — исследование временных рядов котировок, выявление закономерностей и построение прогнозных моделей на основе биржевых данных с помощью статистических методов и машинного обучения.
- **Анализ информационного фона и прогнозирование рыночной динамики** — обработка новостей и комментариев с помощью NLP, выявление связей между текстовыми сигналами и котировками, построение моделей для прогнозирования динамики рынка на основе этих сигналов.
