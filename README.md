# Аналитическая платформа биржевых событий

## О проекте

Проект ориентирован на анализ **российского фондового рынка** и включает два взаимодополняющих направления:

- **Анализ и прогнозирование динамики котировок** — исследование временных рядов котировок, выявление закономерностей и построение прогнозных моделей на основе биржевых данных.
- **Анализ информационного фона и прогнозирование рыночной динамики** — обработка новостей и комментариев с помощью NLP, выявление связей между текстовыми сигналами и котировками и построение прогнозных моделей.

## Источники данных

**Котировки:**
- MOEX ISS API
- MOEX ALGOPACK
- T-Invest API
- Finam Trade API
- Банк России
- Росстат / ЕМИСС

**Новости / комментарии:**
- Интерфакс
- Центр раскрытия корпоративной информации (e-disclosure)
- Банк России
- Московская биржа
- РБК / РБК Инвестиции
- ПРАЙМ
- ТАСС
- Коммерсантъ
- Ведомости
- Smart-Lab
- Telegram-каналы по фондовому рынку
- официальные IR-разделы компаний
- официальные Telegram-каналы компаний и регуляторов
